# Hand model file (not in the repo)

`hand_landmarker.task` — the MediaPipe Hand Landmarker model bundle — is NOT
stored in this repository: the GitHub push route used for this repo carries
text files only and cannot upload the 7.8 MB binary.

To run the program from this repo copy, download the official model and place
it here as `hand_landmarker.task`:

https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

(The full packaged zip includes the model already bundled, so no download is
needed there.)
